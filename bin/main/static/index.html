4 entidades del dominio académico con sus relaciones.

ESTUDIANTE ——< 1:1 >—— CARNET
ESTUDIANTE ——< N:M >—— CURSO
Tabla intermedia: estudiante_curso
03Relaciones JPA

@OneToMany, @ManyToOne, @OneToOne, @ManyToMany

@OneToMany / @ManyToOne — Docente ↔ Curso

// Docente.java
@OneToMany(mappedBy = "docente", cascade = CascadeType.ALL)
private List<Curso> cursos;

// Curso.java (dueño)
@ManyToOne(fetch = FetchType.LAZY)
@JoinColumn(name = "docente_id")
private Docente docente;

@OneToOne — Estudiante ↔ Carnet

// Estudiante.java
@OneToOne(mappedBy = "estudiante", cascade = CascadeType.ALL)
private Carnet carnet;

// Carnet.java (dueño)
@OneToOne
@JoinColumn(name = "estudiante_id", unique = true)
private Estudiante estudiante;

@ManyToMany — Estudiante ↔ Curso

// Estudiante.java (dueño)
@ManyToMany
@JoinTable(name = "estudiante_curso",
  joinColumns = @JoinColumn(name = "estudiante_id"),
  inverseJoinColumns = @JoinColumn(name = "curso_id"))
private List<Curso> cursos;
04Conexión PostgreSQL

Configuración de application.properties

application.properties

spring.datasource.url=jdbc:postgresql://localhost:5432/sistema_academico
spring.datasource.username=postgres
spring.datasource.password=tu_contraseña
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
