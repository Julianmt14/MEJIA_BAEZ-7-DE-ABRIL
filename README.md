# MEJIA_BAEZ-7-DE-ABRIL
MEJIA_BAEZ 7 DE ABRIL

## Spring Boot Project

Este proyecto es una aplicación Spring Boot básica.

### Requisitos
- Java 17+
- Maven 3.6+

### Ejecutar la aplicación
```bash
mvn spring-boot:run
```

La aplicación estará disponible en `http://localhost:8080`.

### Compilar y probar
```bash
mvn clean package
mvn test
```
